Ya resolviste, en el integrador anterior, los dos ejercicios que cierran
el bloque de Git con los tipos de actividad que ya conocés: clasificar
situaciones (`FindInCode`) y elegir la opción correcta (`Quiz`). Esta
página es la continuación de esos ejercicios integradores, pero con un
objetivo distinto: probar mecánicas de interacción nuevas, para no
quedarnos solo con clasificar, ordenar y elegir.

Es un laboratorio — los ejercicios siguen usando Git y GitHub como
excusa (porque ya tenés el contexto fresco del bloque), pero lo que se
evalúa acá es la mecánica en sí, no contenido nuevo del temario.

## Práctica

Son 8 ejercicios, cada uno con una mecánica distinta. Son independientes
entre sí y cada bloque avisa cuándo está resuelto.
