Ya viste, una por una, las 10 entradas de Git y GitHub: qué es el control
de versiones, cómo funciona Git por dentro, el primer commit, el
historial, ramas, merge y conflictos, el remoto, cómo deshacer cambios,
rebase y Pull Requests. En el día a día, un problema de Git casi nunca
aparece aislado — un conflicto de merge, por ejemplo, solo tiene sentido
si entendés ramas, remoto y commits al mismo tiempo.
