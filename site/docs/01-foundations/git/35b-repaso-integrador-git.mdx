Ya viste, una por una, las 15 entradas de Git y GitHub: qué es el control
de versiones, cómo funciona Git por dentro, el primer commit, el
historial, ramas, merge y conflictos, el remoto y sus ramas, cómo deshacer
cambios, etiquetas y versiones, cómo encontrar el commit de un defecto,
rebase, issues y forks, Pull Requests y flujos de trabajo. En el día a día, un problema de Git casi nunca
aparece aislado — un conflicto de merge, por ejemplo, solo tiene sentido
si entendés ramas, remoto y commits al mismo tiempo.

## El proyecto de la lista de deseos

Varios de los ejercicios de abajo usan el mismo proyecto: estás agregando
una **lista de deseos** a la tienda online, en tu rama
`feature/lista-deseos`, mientras el resto del equipo sigue subiendo cambios
a `main`. Los ejercicios de diagnóstico y de comandos sueltos traen sus
propios casos.

## Práctica

Son 8 ejercicios y entre todos cubren las 15 entradas del bloque: cada uno
dice en su objetivo qué entradas repasa. Son independientes entre sí y cada
bloque avisa cuándo está resuelto.
