Ya viste, una por una, las 15 entradas de programación: cómo se ejecuta el
código, variables y tipos, operadores, strings, condicionales, funciones,
arrays, loops, objetos, interfaces y union types, clases, módulos, JSON,
funciones asíncronas y manejo de errores. Un programa real casi nunca usa
una sola de estas cosas a la vez — las combina. Un bug real, también: casi
siempre es la intersección de dos conceptos, no uno solo.
