Ya viste, una por una, las 10 entradas de programación: variables y tipos,
operadores, condicionales, funciones, arrays, loops, objetos, interfaces,
funciones asíncronas y manejo de errores. Un programa real casi nunca usa
una sola de estas cosas a la vez — las combina. Un bug real, también: casi
siempre es la intersección de dos conceptos, no uno solo.
